# Fonts

Self-hosted so the build does not fetch from Google Fonts (`next/font/google` fails on GitHub's runners). Latin subset
of each variable font, as served by Google Fonts in October 2026. All three are under the SIL Open Font License 1.1;
the licence and copyright for each are in `OFL-<family>.txt`.

| File | Family | Weights |
|------|--------|---------|
| `BricolageGrotesque-latin.woff2` | Bricolage Grotesque | 200–800 |
| `Newsreader-latin.woff2`, `Newsreader-Italic-latin.woff2` | Newsreader | 200–800 |
| `JetBrainsMono-latin.woff2` | JetBrains Mono | 100–800 |
