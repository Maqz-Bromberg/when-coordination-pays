title: E3 · Paid attention
result: Paying agents for the attention they relay does not entrench hubs. The hub changes every one or two epochs with or without payment, and with a slowly moving source payment, if anything, shortens hub tenure.
implication: In this model holding attention gives a hub no way to make itself the source, so there is nothing for a monopoly to capture; entrenchment would need agents that can shape where information appears.

## Setup

30 agents on a complete graph, tempered selection T = 0.6, ε = 1, Markov source with τ_E = 200 or 2000. Each agent has
its own self-reinforcement κ_i in [0, 0.55], below T so it never locks in: how stably it keeps its attention.

- **Payoff per 200-round epoch:** a × (relay attention received, counted only when the agent is not the source) minus its
  distance from the source; a = 0 is the control.
- **Selection:** after each epoch the lowest earner copies the best earner's κ, plus Gaussian noise (0.05).
- **Runs:** 150 epochs, 4 repeats. Script: `python -m nichenet.experiments.e3`. Data: `data/site/e3.json`.

## Results

| τ_E | payment a | mean κ, start → end | hub tenure (epochs) | takeovers by a less reliable agent |
|---|---|---|---|---|
| 200 | 0 / 0.5 / 1 / 2 | 0.31 → 0.54 in all four | 1.2 | 41–46% |
| 2000 | 0 / 0.5 / 1 / 2 | 0.31 → 0.55 in all four | 2.3, 2.2, 1.8, 1.8 | 19%, 18%, 12%, 8% |

- **Payment changes nothing.** κ rises to its cap at every payment, including none: attending stably to the source
  shortens an agent's own distance, so reliability pays for private reasons.
- **Hubs do not entrench.** The agent with the most relay attention follows the source's recent history.
- **Why.** A hub's κ shapes only its own attention and never feeds back on the source; being listened to is a by-product
  of listening to the source.
- **Caveat.** κ reaches its cap, so late in the run the spread of κ is small and the takeover measure says little.

## Follow-ups

Both stay null: a = 0 to 2 makes no difference in either.

| variant | τ_E = 200: hub tenure / mean κ at end | τ_E = 2000: hub tenure / mean κ at end |
|---|---|---|
| complete graph, next source drawn by attention | 1.3–1.4 / 0.54 | 1.9–2.1 / 0.55 |
| sparse graph (4 neighbours), external source | 1.6 / 0.26–0.29 | 8.1–8.4 / 0.26–0.28 |
| sparse graph, next source drawn by attention | 1.6–1.7 / 0.28–0.29 | 8.7–9.4 / 0.26–0.29 |

- **Next source drawn by attention:** attention now buys future source status; on complete graphs nothing changes.
- **Sparse graphs:** relays matter and relay hubs persist much longer (8–9 epochs at τ_E = 2000), but payment still does
  not lengthen tenure, κ no longer rises, and takeovers by a less reliable agent run at chance (about 50%).

Data: `data/site/e3_endogenous.json`, `e3_sparse.json`, `e3_endogenous_sparse.json`.
