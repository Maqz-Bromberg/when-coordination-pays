## Design

A 2 × 2 factorial (`nichenet/compare.py`). Every cell runs W ← (1 − η)W + η·N[U^p] on the same 7 × 7 lattice with the
same source schedule, and differs only in:

- **Budget N:** each agent's attention sums to one, or one global sum (material).
- **Usage U of link k → i:** closeness to the news, D_k^{κ−1} W_ki^κ, or the squared Kirchhoff current I_e² when the
  source broadcasts to everyone (flow).

The per-agent/closeness cell is the attention model with tempered selection (T = 1/p). The shared/flow cell has Corson's
optimum as its steady-load fixed point (γ = 1/p − 1). Both are tested in `py/tests/test_compare.py`.

**Setup:** p from 0.4 to 20, η = 0.05, 3000 rounds, 3 repeats; source fixed at a corner, moving (τ_E = 50) or random.
Loops count the independent cycles of the backbone, the links carrying at least 0.1 of the receiving agent's strongest
link. Script: `python -m nichenet.experiments.e6`. Data: `data/site/e6.json`.

## Results

Mean loops (maximum 36), fixed / random source:

| cell | p = 0.5 | 0.67 | 1 | 2 | 3 | 5 | 10 |
|---|---|---|---|---|---|---|---|
| per agent, flow | 36 / 36 | 5.7 / 36 | 0 / 32.7 | 0 / 18.7 | 0 / 18.0 | 0 / 17.3 | 0 / 16.3 |
| shared, flow | 36 / 36 | 0 / 14.3 | 0 / 3.3 | 0 / 0.7 | collapsed / 0 | collapsed / 0 | collapsed |
| per agent, closeness, κ = 0 | 36 / 36 | 36 / 36 | 36 / 36 | 36 / 36 | 36 / 36 | 36 / 36 | 36 / 36 |
| per agent, closeness, κ = 0.25 | 36 / 36 | 36 / 36 | 36 / 36 | 36 / 36 | 36 / 36 | 0 / 25 | 0 / 1 |
| per agent, closeness, κ = 0.5 | 36 / 36 | 36 / 36 | 36 / 36 | 36 / 35.3 | 0 / 0 | 0 / 0 | 0 / 0 |

"Collapsed": in most repeats the links carrying at least 10⁻¹⁰ of the largest weight no longer connect all agents; the
shared budget has concentrated onto part of the graph and loop counts are meaningless. A per-agent budget never collapses,
because every agent keeps a link; under a moving source with κ > 0 it can fragment into a forest, which the loop count
(E − V + components) handles.

1. **Trees need self-reinforcement.** Flow reinforces itself: a stronger link carries more current. Closeness at κ = 0
   does not, so two equally close parents tie forever and every loop survives. Trees appear past p ≈ 1/κ, where the
   symmetric state loses stability (T = κ): between p = 3 and 5 for κ = 0.25, at p = 3 for κ = 0.5.
2. **A fluctuating source keeps loops only with flow.** With flow, a random source keeps 15–36 loops under a per-agent
   budget. With closeness, a random source only delays the transition (κ = 0.25: trees from p = 10 instead of 5), after
   which the network locks into some tree whatever the source does.
3. **The budget decides robustness and cost.** A per-agent budget gives trees or forests, never a collapse, with
   dissipation at most about 4.5× the even lattice. A shared budget puts the tree transition exactly at Corson's
   γ = 1 (p = 1/2) and, at strong concentration, collapses, with dissipation growing by orders of magnitude.
