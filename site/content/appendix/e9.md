## Design

The [E8](/appendix/e8/) grid, repeats and environments, with three reward rules that all keep the strength factor A^κ:

- **position** (the model): D_k^{κ−1} A_ki^κ, closeness to the seeded agent through the network;
- **evidence:** λ^{1−κ} A_ki^κ with λ = ρ on the seeded agent and 1 elsewhere, a Kelly or multiplicative-weights reward.
  It equals the position rule in the symmetric state, so any difference comes from relays;
- **evidence, noise-tuned:** the same with the true likelihood ratio λ* = 1 + N(1 − ν)/ν.

The bound is the exact Bayes filter over the source, knowing ν and τ_E. Kernel switches: `reward="likelihood"`, `lam`;
the runs also record the information cost. Script: `python -m nichenet.experiments.e9`. Data: `data/site/e9.json`.

## Results

| N, ν | benefit / ln(N−1): position / evidence / noise-tuned / Bayes | tracking: position / evidence / Bayes |
|---|---|---|
| 10, 0.5 | 0.94 / 0.86 / 0.76 / 0.97 | 0.93 / 0.79 / 0.97 |
| 10, 0.75 | 0.67 / 0.57 / 0.50 / 0.92 | 0.58 / 0.49 / 0.92 |
| 80, 0.5 | 0.96 / 0.90 / 0.81 / 0.98 | 0.91 / 0.72 / 0.97 |
| 80, 0.75 | 0.75 / 0.70 / 0.59 / 0.97 | 0.43 / 0.36 / 0.96 |

- **Relays are worth 5–10 points under heavy noise;** at ν = 0.25 the rules are within a point, and without noise identical.
- **Noise-tuning backfires.** The update averages rewards instead of multiplying beliefs, so a sharper likelihood copies
  the latest signal.
- **Position is within 1–3% of Bayes up to ν = 0.5,** and far from it at 0.75: with ε = 1 the group averages over about
  1.4 rounds, while the filter uses every signal since the source moved.
- **Structural cost is set by the structure:** the Bayes filter builds the same hub at the same 1.8–2.0×.
- **What each rule stands for.** Position: routing and social learning, with collective error correction through relays.
  Evidence: individual inference, each agent learning alone.
